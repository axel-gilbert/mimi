# Mimi 💗

**キー1つで、大切な人の画面に小さなハートを届けよう。**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

MimiはWindows向けの小さな無料アプリです。ショートカットを押すと、かわいい音とともに小さなアニメーションのハートが相手の画面の隅にふわっと浮かびます。大きなハート、短いメッセージ、画像、GIFも送れます。アカウントもサーバーも不要。2台のPCが直接やり取りし、すべて暗号化されます。

## インストール（2台とも）

1. [最新リリース](https://github.com/axel-gilbert/mimi/releases/latest)から `Mimi-…-win-x64.exe` をダウンロードします。
2. ダブルクリックします。Windowsに *「Windows によってPCが保護されました」* と表示されたら、**詳細情報**をクリックして**実行**を押します。
3. **はい**をクリックしてインストールし、Windowsがネットワークアクセスを求めたら**はい / 許可**を押します。
4. 名前を入力します。Mimiは時計のそば（小さなハートのアイコン）に常駐し、Windowsと一緒に起動します。

## 2台のPCをつなぐ（最初の1回だけ）

この手順では、2台とも同じWi-Fiにつないでおいてください。

1. 1台目のPCで**コードを作成**をクリックします。6桁のコードが表示されます。
2. 2台目のPCでそのコードを入力し、**参加**をクリックします。完了です 💞

## 使い方

- **Ctrl + Alt + H**：ハートを送ります。押し続けると、どんどん大きくなる特大ハートになります。
- **Ctrl + Alt + M**：メッセージを書く、または画像やGIFを送ります。画面の中央に表示されます。
- 相手と同時に押すと、サプライズが起きます。
- ハートのアイコンを右クリックすると**おやすみモード**が使えます（10分〜24時間、または自分で解除するまで）。
- Mimiは自動で更新されます。
