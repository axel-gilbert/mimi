# Mimi 💗

**Kirim hati-hati kecil ke layar belahan jiwamu hanya dengan satu tombol.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi adalah aplikasi mungil gratis untuk Windows. Saat kamu menekan pintasan, hati-hati kecil beranimasi melayang naik di sudut layar pasanganmu, lengkap dengan suara imut. Kamu juga bisa mengirim hati besar, pesan singkat, gambar, atau GIF. Tanpa akun, tanpa server: kedua PC saling berbicara langsung, dan semuanya terenkripsi.

## Pasang (di kedua PC)

1. Unduh `Mimi-…-win-x64.exe` dari [rilis terbaru](https://github.com/axel-gilbert/mimi/releases/latest).
2. Klik dua kali. Kalau Windows menampilkan *"Windows protected your PC"*, klik **More info**, lalu **Run anyway**.
3. Klik **Ya** untuk memasang, lalu **Ya / Izinkan** kalau Windows meminta akses jaringan.
4. Ketik namamu. Sekarang Mimi tinggal di dekat jam (ikon hati kecil) dan otomatis jalan bersama Windows.

## Hubungkan kedua PC (cukup sekali)

Di langkah ini, kedua PC harus berada di Wi-Fi yang sama.

1. Di PC pertama, klik **Buat kode**: kode 6 digit akan muncul.
2. Di PC kedua, ketik kodenya lalu klik **Gabung**. Selesai 💞

## Cara memakai

- **Ctrl + Alt + H**: kirim hati. Tahan tombolnya untuk hati besar yang terus membesar.
- **Ctrl + Alt + M**: tulis pesan, atau kirim gambar atau GIF, tampil di tengah layar.
- Tekan bersamaan dengan pasanganmu untuk kejutan.
- Klik kanan ikon hati untuk **Jangan ganggu** (10 menit sampai 24 jam, atau sampai kamu mematikannya).
- Mimi memperbarui dirinya sendiri.
