# Mimi 💗

**ส่งหัวใจดวงเล็ก ๆ ไปที่หน้าจอของคนสำคัญด้วยการกดปุ่มเดียว**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi เป็นแอปเล็ก ๆ ฟรีสำหรับ Windows เมื่อคุณกดปุ่มลัด หัวใจแอนิเมชันดวงจิ๋วจะลอยขึ้นมาที่มุมหน้าจอของคนสำคัญพร้อมเสียงน่ารัก ๆ นอกจากนี้ยังส่งหัวใจดวงใหญ่ ข้อความสั้น ๆ รูปภาพ หรือ GIF ได้ด้วย ไม่ต้องมีบัญชี ไม่ต้องมีเซิร์ฟเวอร์ คอมพิวเตอร์สองเครื่องคุยกันโดยตรง และทุกอย่างถูกเข้ารหัส

## ติดตั้ง (ทั้งสองเครื่อง)

1. ดาวน์โหลด `Mimi-…-win-x64.exe` จาก[รุ่นล่าสุด](https://github.com/axel-gilbert/mimi/releases/latest)
2. ดับเบิลคลิกที่ไฟล์ ถ้า Windows ขึ้นว่า *"Windows protected your PC"* ให้คลิก **More info** แล้วคลิก **Run anyway**
3. คลิก **ใช่** เพื่อติดตั้ง แล้วคลิก **ใช่ / อนุญาต** ถ้า Windows ขอสิทธิ์เข้าถึงเครือข่าย
4. พิมพ์ชื่อของคุณ ตอนนี้ Mimi จะอยู่ข้างนาฬิกา (เป็นไอคอนหัวใจดวงเล็ก) และเริ่มทำงานพร้อม Windows

## เชื่อมต่อสองเครื่อง (ทำครั้งเดียว)

ขั้นตอนนี้ทั้งสองเครื่องต้องอยู่ใน Wi-Fi เดียวกัน

1. ที่เครื่องแรก คลิก **สร้างรหัส** แล้วรหัส 6 หลักจะปรากฏขึ้น
2. ที่เครื่องที่สอง พิมพ์รหัสนั้น แล้วคลิก **เข้าร่วม** เสร็จแล้ว 💞

## วิธีใช้

- **Ctrl + Alt + H**: ส่งหัวใจ กดค้างไว้เพื่อส่งหัวใจดวงใหญ่ที่โตขึ้นเรื่อย ๆ
- **Ctrl + Alt + M**: เขียนข้อความ หรือส่งรูปหรือ GIF ซึ่งจะแสดงกลางหน้าจอ
- กดพร้อมกับคนสำคัญของคุณเพื่อรับเซอร์ไพรส์
- คลิกขวาที่ไอคอนหัวใจเพื่อเลือก **ห้ามรบกวน** (ตั้งแต่ 10 นาทีถึง 24 ชั่วโมง หรือจนกว่าคุณจะปิด)
- Mimi อัปเดตตัวเองอัตโนมัติ
