# Mimi 💗

**Lähetä pieniä sydämiä toisen puolikkaasi näytölle yhdellä näppäilyllä.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi on pieni ilmainen Windows-sovellus. Kun painat pikanäppäintä, pienet animoidut sydämet leijuvat kumppanisi näytön kulmaan suloisen äänen kera. Voit lähettää myös ison sydämen, lyhyen viestin, kuvan tai GIFin. Ei tiliä, ei palvelinta: kaksi tietokonetta puhuvat suoraan keskenään, ja kaikki on salattua.

## Asennus (molemmille tietokoneille)

1. Lataa `Mimi-…-win-x64.exe` [uusimmasta julkaisusta](https://github.com/axel-gilbert/mimi/releases/latest).
2. Kaksoisnapsauta sitä. Jos Windows sanoo *"Windows suojasi tietokonettasi"*, napsauta **Lisätietoja** ja sitten **Suorita kuitenkin**.
3. Napsauta **Kyllä** asentaaksesi, ja sitten **Kyllä / Salli**, jos Windows kysyy verkkoyhteyden sallimista.
4. Kirjoita nimesi. Mimi asuu nyt kellon vieressä (pieni sydänkuvake) ja käynnistyy Windowsin mukana.

## Yhdistä kaksi tietokonetta (vain kerran)

Molempien tietokoneiden on oltava samassa wifissä tämän vaiheen ajan.

1. Napsauta ensimmäisellä tietokoneella **Luo koodi**: näkyviin tulee 6-numeroinen koodi.
2. Kirjoita koodi toisella tietokoneella ja napsauta **Liity**. Valmista 💞

## Käyttö

- **Ctrl + Alt + H**: lähetä sydän. Pidä näppäimiä pohjassa, niin saat kasvavan ison sydämen.
- **Ctrl + Alt + M**: kirjoita viesti tai lähetä kuva tai GIF, joka näkyy näytön keskellä.
- Paina samaan aikaan kumppanisi kanssa, niin saat yllätyksen.
- Napsauta sydänkuvaketta hiiren kakkospainikkeella ja valitse **Älä häiritse** (10 minuutista 24 tuntiin tai kunnes lopetat).
- Mimi päivittää itsensä.
