# Mimi 💗

**키 하나로 내 반쪽의 화면에 작은 하트를 보내요.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi는 Windows용 작고 무료인 앱이에요. 단축키를 누르면 귀여운 소리와 함께 작은 애니메이션 하트가 상대방 화면 구석에 둥실 떠올라요. 큰 하트, 짧은 메시지, 사진, GIF도 보낼 수 있어요. 계정도 서버도 필요 없어요. 두 PC가 직접 대화하고, 모든 내용은 암호화돼요.

## 설치 (두 PC 모두)

1. [최신 릴리스](https://github.com/axel-gilbert/mimi/releases/latest)에서 `Mimi-…-win-x64.exe`를 내려받으세요.
2. 더블 클릭하세요. Windows가 *"Windows의 PC 보호"* 라고 하면 **추가 정보**를 누른 다음 **실행**을 누르세요.
3. **예**를 눌러 설치하고, Windows가 네트워크 접근을 물어보면 **예 / 허용**을 누르세요.
4. 이름을 입력하세요. 이제 Mimi는 시계 옆(작은 하트 아이콘)에 자리 잡고 Windows와 함께 시작돼요.

## 두 PC 연결하기 (딱 한 번)

이 단계에서는 두 PC가 같은 Wi-Fi에 있어야 해요.

1. 첫 번째 PC에서 **코드 만들기**를 누르세요. 6자리 코드가 나타나요.
2. 두 번째 PC에서 코드를 입력하고 **참여**를 누르세요. 끝! 💞

## 사용하기

- **Ctrl + Alt + H**: 하트 보내기. 키를 계속 누르고 있으면 점점 커지는 큰 하트가 가요.
- **Ctrl + Alt + M**: 메시지를 쓰거나 사진 또는 GIF를 보내요. 화면 가운데에 표시돼요.
- 내 반쪽과 동시에 누르면 깜짝 선물이 있어요.
- 하트 아이콘을 오른쪽 클릭하면 **방해 금지**를 쓸 수 있어요 (10분부터 24시간까지, 또는 내가 끌 때까지).
- Mimi는 스스로 업데이트돼요.
