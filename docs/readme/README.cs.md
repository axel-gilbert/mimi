# Mimi 💗

**Posílej malá srdíčka na obrazovku své drahé polovičky jediným stiskem klávesy.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi je malá bezplatná aplikace pro Windows. Když stiskneš zkratku, v rohu obrazovky tvého partnera se s roztomilým zvukem vznesou malá animovaná srdíčka. Můžeš poslat i velké srdce, krátkou zprávu, obrázek nebo GIF. Žádný účet, žádný server: oba počítače spolu komunikují přímo a všechno je šifrované.

## Instalace (na obou počítačích)

1. Stáhni `Mimi-…-win-x64.exe` z [nejnovějšího vydání](https://github.com/axel-gilbert/mimi/releases/latest).
2. Dvakrát na něj klikni. Pokud Windows zobrazí *"Systém Windows ochránil váš počítač"*, klikni na **Další informace** a potom na **Přesto spustit**.
3. Klikni na **Ano** pro instalaci a pak na **Ano / Povolit**, pokud se Windows zeptá na přístup k síti.
4. Zadej své jméno. Mimi teď bydlí vedle hodin (malá ikona srdce) a spouští se s Windows.

## Propojení dvou počítačů (jen jednou)

V tomto kroku musí být oba počítače na stejné wifi.

1. Na prvním počítači klikni na **Vytvořit kód**: zobrazí se 6místný kód.
2. Na druhém počítači kód zadej a klikni na **Připojit**. Hotovo 💞

## Používání

- **Ctrl + Alt + H**: pošle srdíčko. Podrž klávesy stisknuté pro velké srdce, které roste.
- **Ctrl + Alt + M**: napíše zprávu nebo pošle obrázek či GIF, zobrazí se uprostřed obrazovky.
- Stiskni ve stejnou chvíli jako tvůj partner a čeká vás překvapení.
- Klikni pravým tlačítkem na ikonu srdce pro **Nerušit** (od 10 minut do 24 hodin, nebo dokud nevypneš).
- Mimi se aktualizuje samo.
