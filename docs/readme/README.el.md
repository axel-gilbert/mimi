# Mimi 💗

**Στείλε μικρές καρδούλες στην οθόνη του ταιριού σου με ένα πλήκτρο.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Το Mimi είναι μια μικρή δωρεάν εφαρμογή για Windows. Όταν πατάς μια συντόμευση, μικρές κινούμενες καρδούλες αιωρούνται στη γωνία της οθόνης του συντρόφου σου, με έναν γλυκό ήχο. Μπορείς επίσης να στείλεις μια μεγάλη καρδιά, ένα σύντομο μήνυμα, μια εικόνα ή ένα GIF. Χωρίς λογαριασμό, χωρίς διακομιστή: οι δύο υπολογιστές μιλούν απευθείας μεταξύ τους και όλα είναι κρυπτογραφημένα.

## Εγκατάσταση (και στους δύο υπολογιστές)

1. Κατέβασε το `Mimi-…-win-x64.exe` από την [τελευταία έκδοση](https://github.com/axel-gilbert/mimi/releases/latest).
2. Κάνε διπλό κλικ πάνω του. Αν τα Windows πουν *"Τα Windows προστάτευσαν τον υπολογιστή σας"*, κάνε κλικ στο **Περισσότερες πληροφορίες** και μετά στο **Εκτέλεση ούτως ή άλλως**.
3. Κάνε κλικ στο **Ναι** για εγκατάσταση και μετά στο **Ναι / Να επιτρέπεται**, αν τα Windows ζητήσουν πρόσβαση στο δίκτυο.
4. Γράψε το όνομά σου. Το Mimi μένει πλέον δίπλα στο ρολόι (ένα μικρό εικονίδιο καρδιάς) και ξεκινά με τα Windows.

## Σύνδεση των δύο υπολογιστών (μόνο μία φορά)

Και οι δύο υπολογιστές πρέπει να είναι στο ίδιο Wi-Fi σε αυτό το βήμα.

1. Στον πρώτο υπολογιστή, κάνε κλικ στο **Δημιουργία κωδικού**: εμφανίζεται ένας κωδικός 6 ψηφίων.
2. Στον δεύτερο υπολογιστή, πληκτρολόγησε τον κωδικό και κάνε κλικ στο **Σύνδεση**. Έτοιμο 💞

## Χρήση

- **Ctrl + Alt + H**: στείλε μια καρδούλα. Κράτα τα πλήκτρα πατημένα για μια μεγάλη καρδιά που μεγαλώνει.
- **Ctrl + Alt + M**: γράψε ένα μήνυμα ή στείλε μια εικόνα ή ένα GIF, που εμφανίζεται στο κέντρο της οθόνης.
- Πάτα την ίδια στιγμή με τον σύντροφό σου για μια έκπληξη.
- Κάνε δεξί κλικ στο εικονίδιο της καρδιάς για **Μην ενοχλείτε** (από 10 λεπτά έως 24 ώρες, ή μέχρι να το κλείσεις).
- Το Mimi ενημερώνεται μόνο του.
