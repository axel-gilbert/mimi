# Mimi 💗

**Trimite inimioare pe ecranul jumătății tale cu o singură tastă.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi este o aplicație mică și gratuită pentru Windows. Când apeși o scurtătură, mici inimioare animate plutesc în colțul ecranului partenerului tău, cu un sunet drăguț. Poți trimite și o inimă mare, un mesaj scurt, o poză sau un GIF. Fără cont, fără server: cele două PC-uri vorbesc direct între ele, iar totul este criptat.

## Instalare (pe ambele PC-uri)

1. Descarcă `Mimi-…-win-x64.exe` din [ultima versiune](https://github.com/axel-gilbert/mimi/releases/latest).
2. Dă dublu clic pe el. Dacă Windows spune *„Windows a protejat computerul”*, apasă **Mai multe informații**, apoi **Rulează oricum**.
3. Apasă **Da** pentru a instala, apoi **Da / Permite** dacă Windows cere acces la rețea.
4. Scrie-ți numele. Mimi stă acum lângă ceas (o mică inimioară) și pornește cu Windows.

## Conectează cele două PC-uri (o singură dată)

Pentru acest pas, ambele PC-uri trebuie să fie în aceeași rețea Wi-Fi.

1. Pe primul PC, apasă **Creează un cod**: apare un cod din 6 cifre.
2. Pe al doilea PC, introdu codul și apasă **Alătură-te**. Gata 💞

## Cum se folosește

- **Ctrl + Alt + H**: trimite o inimioară. Ține tastele apăsate pentru o inimă mare care crește.
- **Ctrl + Alt + M**: scrie un mesaj sau trimite o poză ori un GIF, afișate în mijlocul ecranului.
- Apasă în același timp cu partenerul tău pentru o surpriză.
- Clic dreapta pe pictograma inimii pentru **Nu deranja** (de la 10 minute la 24 de ore, sau până îl oprești).
- Mimi se actualizează singur.
