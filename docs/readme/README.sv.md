# Mimi 💗

**Skicka små hjärtan till din andra hälfts skärm med en enda tangent.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi är en liten gratisapp för Windows. När du trycker på en genväg svävar små animerade hjärtan upp i hörnet av din partners skärm, med ett gulligt ljud. Du kan också skicka ett stort hjärta, ett kort meddelande, en bild eller en GIF. Inget konto, ingen server: de två datorerna pratar direkt med varandra, och allt är krypterat.

## Installera (på båda datorerna)

1. Ladda ner `Mimi-…-win-x64.exe` från den [senaste versionen](https://github.com/axel-gilbert/mimi/releases/latest).
2. Dubbelklicka på den. Om Windows säger *"Windows har skyddat din dator"*, klicka på **Mer info** och sedan **Kör ändå**.
3. Klicka på **Ja** för att installera, sedan **Ja / Tillåt** om Windows frågar om nätverksåtkomst.
4. Skriv ditt namn. Mimi bor nu bredvid klockan (en liten hjärtikon) och startar med Windows.

## Koppla ihop de två datorerna (bara en gång)

Båda datorerna måste vara på samma wifi för det här steget.

1. På den första datorn, klicka på **Skapa en kod**: en kod med 6 siffror visas.
2. På den andra datorn, skriv in koden och klicka på **Anslut**. Klart 💞

## Använd den

- **Ctrl + Alt + H**: skicka ett hjärta. Håll tangenterna nedtryckta för ett stort hjärta som växer.
- **Ctrl + Alt + M**: skriv ett meddelande, eller skicka en bild eller en GIF, som visas mitt på skärmen.
- Tryck samtidigt som din partner för en överraskning.
- Högerklicka på hjärtikonen för **Stör ej** (10 minuter till 24 timmar, eller tills du stänger av).
- Mimi uppdaterar sig själv.
