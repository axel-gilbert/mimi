# Mimi 💗

**با یک کلید، قلب‌های کوچک را روی صفحهٔ نیمهٔ دلت بفرست.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi یک برنامهٔ کوچک و رایگان برای Windows است. وقتی میان‌بر را می‌زنی، قلب‌های کوچک متحرک با یک صدای بامزه در گوشهٔ صفحهٔ نیمهٔ دلت بالا می‌روند. می‌توانی قلب بزرگ، پیام کوتاه، عکس یا GIF هم بفرستی. بدون حساب کاربری، بدون سرور: دو رایانه مستقیم با هم حرف می‌زنند و همه‌چیز رمزگذاری می‌شود.

## نصب (روی هر دو رایانه)

1. فایل `Mimi-…-win-x64.exe` را از [آخرین نسخه](https://github.com/axel-gilbert/mimi/releases/latest) دانلود کن.
2. روی آن دوبار کلیک کن. اگر Windows نوشت *«Windows protected your PC»*، روی **More info** و بعد **Run anyway** کلیک کن.
3. برای نصب روی **بله** کلیک کن، و اگر Windows دسترسی به شبکه را پرسید، **بله / اجازه بده**.
4. نامت را بنویس. Mimi حالا کنار ساعت (با یک آیکون قلب کوچک) می‌نشیند و همراه Windows اجرا می‌شود.

## اتصال دو رایانه (فقط یک بار)

برای این مرحله هر دو رایانه باید روی یک Wi-Fi باشند.

1. در رایانهٔ اول روی **ساخت کد** کلیک کن: یک کد ۶ رقمی نمایش داده می‌شود.
2. در رایانهٔ دوم کد را وارد کن و روی **پیوستن** کلیک کن. تمام 💞

## طرز استفاده

- **Ctrl + Alt + H**: فرستادن قلب. کلیدها را نگه دار تا قلبی بزرگ و رشدکننده بفرستی.
- **Ctrl + Alt + M**: نوشتن پیام، یا فرستادن عکس یا GIF که در وسط صفحه نمایش داده می‌شود.
- همزمان با نیمهٔ دلت بزن تا غافلگیر شوید.
- روی آیکون قلب راست‌کلیک کن تا **مزاحم نشوید** را ببینی (از ۱۰ دقیقه تا ۲۴ ساعت، یا تا خودت خاموش کنی).
- Mimi خودش را به‌روز می‌کند.
