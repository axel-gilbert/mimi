# Mimi 💗

**Mande corações para a tela da sua metade com uma só tecla.**

<p align="center"><img src="../demo.gif" width="560" alt="Demonstração do Mimi"></p>

O Mimi é um aplicativo pequenininho e gratuito para Windows. Quando você aperta um atalho, corações animados flutuam no canto da tela do seu par, com um sonzinho fofo. Você também pode mandar um coração grande, uma mensagem curta, uma imagem ou um GIF. Sem conta, sem servidor: os dois PCs conversam diretamente e tudo é criptografado.

## Instalação (nos dois PCs)

1. Baixe o `Mimi-…-win-x64.exe` na [última versão](https://github.com/axel-gilbert/mimi/releases/latest).
2. Dê um duplo clique. Se o Windows disser *"O Windows protegeu seu computador"*, clique em **Mais informações** e depois em **Executar assim mesmo**.
3. Clique em **Sim** para instalar e depois em **Sim / Permitir** se o Windows pedir acesso à rede.
4. Digite seu nome. O Mimi fica ao lado do relógio (um ícone de coração) e inicia junto com o Windows.

## Conecte os dois PCs (só uma vez)

Nesta etapa, os dois PCs precisam estar no mesmo Wi-Fi.

1. No primeiro PC, clique em **Criar um código**: aparece um código de 6 dígitos.
2. No segundo PC, digite o código e clique em **Entrar**. Pronto 💞

## Use

- **Ctrl + Alt + H**: envia um coração. Segure as teclas para um coração grande que cresce.
- **Ctrl + Alt + M**: escreve uma mensagem ou envia uma imagem ou um GIF, exibido no meio da tela.
- Aperte ao mesmo tempo que o seu par para uma surpresa.
- Clique com o botão direito no ícone do coração para ativar o **Não perturbe** (de 10 minutos a 24 horas, ou até você desligar).
- O Mimi se atualiza sozinho.
