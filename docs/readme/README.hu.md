# Mimi 💗

**Küldj apró szívecskéket a párod képernyőjére egyetlen billentyűvel.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

A Mimi egy apró, ingyenes Windows-alkalmazás. Amikor megnyomsz egy gyorsbillentyűt, kis animált szívecskék lebegnek fel a párod képernyőjének sarkában, egy cuki hang kíséretében. Küldhetsz nagy szívet, rövid üzenetet, képet vagy GIF-et is. Nincs fiók, nincs szerver: a két gép közvetlenül beszélget egymással, és minden titkosított.

## Telepítés (mindkét gépen)

1. Töltsd le a `Mimi-…-win-x64.exe` fájlt a [legfrissebb kiadásból](https://github.com/axel-gilbert/mimi/releases/latest).
2. Kattints rá duplán. Ha a Windows azt mondja: *"A Windows megvédte a számítógépét"*, kattints a **További információ**, majd a **Futtatás mindenképpen** gombra.
3. Kattints az **Igen** gombra a telepítéshez, majd az **Igen / Engedélyezés** gombra, ha a Windows hálózati hozzáférést kér.
4. Írd be a neved. A Mimi mostantól az óra mellett lakik (egy kis szív ikon), és a Windowszal együtt indul.

## A két gép összekapcsolása (csak egyszer)

Ehhez a lépéshez mindkét gépnek ugyanazon a wifin kell lennie.

1. Az első gépen kattints a **Kód létrehozása** gombra: megjelenik egy 6 számjegyű kód.
2. A második gépen írd be a kódot, és kattints a **Csatlakozás** gombra. Kész 💞

## Használat

- **Ctrl + Alt + H**: szívecske küldése. Tartsd nyomva a billentyűket egy növekvő nagy szívért.
- **Ctrl + Alt + M**: üzenet írása, vagy kép vagy GIF küldése, amely a képernyő közepén jelenik meg.
- Nyomd meg a párodéval egyszerre, és meglepetés vár.
- Kattints jobb gombbal a szív ikonra a **Ne zavarjanak** módhoz (10 perctől 24 óráig, vagy amíg ki nem kapcsolod).
- A Mimi magától frissül.
