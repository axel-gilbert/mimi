# Mimi 💗

**Schick kleine Herzen mit einer einzigen Taste auf den Bildschirm deiner besseren Hälfte.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi-Demo"></p>

Mimi ist eine winzige, kostenlose App für Windows. Wenn du eine Tastenkombination drückst, schweben kleine animierte Herzen mit einem süßen Sound in der Ecke des Bildschirms deines Partners hoch. Du kannst auch ein großes Herz, eine kurze Nachricht, ein Bild oder ein GIF senden. Kein Konto, kein Server: Die beiden PCs sprechen direkt miteinander, und alles ist verschlüsselt.

## Installation (auf beiden PCs)

1. Lade `Mimi-…-win-x64.exe` von der [neuesten Version](https://github.com/axel-gilbert/mimi/releases/latest) herunter.
2. Doppelklick darauf. Wenn Windows *„Der Computer wurde durch Windows geschützt“* meldet, klick auf **Weitere Informationen** und dann auf **Trotzdem ausführen**.
3. Klick auf **Ja**, um zu installieren, und dann auf **Ja / Zulassen**, falls Windows nach Netzwerkzugriff fragt.
4. Gib deinen Namen ein. Mimi wohnt jetzt neben der Uhr (ein kleines Herz-Symbol) und startet mit Windows.

## Die beiden PCs verbinden (nur einmal)

Für diesen Schritt müssen beide PCs im selben WLAN sein.

1. Klick auf dem ersten PC auf **Code erstellen**: Ein 6-stelliger Code erscheint.
2. Gib auf dem zweiten PC den Code ein und klick auf **Beitreten**. Fertig 💞

## So geht's

- **Ctrl + Alt + H**: ein Herz senden. Halte die Tasten gedrückt für ein großes Herz, das wächst.
- **Ctrl + Alt + M**: eine Nachricht schreiben oder ein Bild bzw. GIF senden, in der Mitte des Bildschirms angezeigt.
- Drück gleichzeitig mit deinem Partner für eine Überraschung.
- Rechtsklick auf das Herz-Symbol für **Nicht stören** (10 Minuten bis 24 Stunden oder bis du es ausschaltest).
- Mimi aktualisiert sich selbst.
