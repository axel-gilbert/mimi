# Mimi 💗

**Отправляй сердечки на экран своей половинки одной клавишей.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi — крошечное бесплатное приложение для Windows. Когда ты нажимаешь сочетание клавиш, в углу экрана твоей половинки всплывают маленькие анимированные сердечки под милый звук. Ещё можно отправить большое сердце, короткое сообщение, картинку или GIF. Без аккаунта, без сервера: два ПК общаются напрямую, и всё зашифровано.

## Установка (на обоих ПК)

1. Скачай `Mimi-…-win-x64.exe` со [страницы последнего релиза](https://github.com/axel-gilbert/mimi/releases/latest).
2. Дважды щёлкни по нему. Если Windows напишет *«Windows защитила ваш компьютер»*, нажми **Подробнее**, затем **Выполнить в любом случае**.
3. Нажми **Да**, чтобы установить, затем **Да / Разрешить**, если Windows запросит доступ к сети.
4. Введи своё имя. Теперь Mimi живёт рядом с часами (маленький значок-сердечко) и запускается вместе с Windows.

## Соедини два ПК (только один раз)

На этом шаге оба ПК должны быть в одной сети Wi-Fi.

1. На первом ПК нажми **Создать код**: появится 6-значный код.
2. На втором ПК введи код и нажми **Подключиться**. Готово 💞

## Как пользоваться

- **Ctrl + Alt + H**: отправить сердечко. Удерживай клавиши, чтобы получилось большое растущее сердце.
- **Ctrl + Alt + M**: написать сообщение или отправить картинку или GIF, они появятся в центре экрана.
- Нажми одновременно со своей половинкой — будет сюрприз.
- Щёлкни правой кнопкой по значку сердечка, чтобы включить **Не беспокоить** (от 10 минут до 24 часов или пока не отключишь).
- Mimi обновляется сам.
