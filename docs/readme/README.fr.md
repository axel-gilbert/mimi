# Mimi 💗

**Envoie de petits cœurs sur l'écran de ta moitié en une seule touche.**

<p align="center"><img src="../demo.gif" width="560" alt="Démo de Mimi"></p>

Mimi est une toute petite application gratuite pour Windows. Quand tu appuies sur un raccourci, de petits cœurs animés s'envolent dans le coin de l'écran de ton partenaire, avec un son tout mignon. Tu peux aussi envoyer un gros cœur, un petit message, une image ou un GIF. Pas de compte, pas de serveur : les deux PC se parlent directement, et tout est chiffré.

## Installation (sur les deux PC)

1. Télécharge `Mimi-…-win-x64.exe` depuis la [dernière version](https://github.com/axel-gilbert/mimi/releases/latest).
2. Double-clique dessus. Si Windows affiche *« Windows a protégé votre ordinateur »*, clique sur **Informations complémentaires**, puis sur **Exécuter quand même**.
3. Clique sur **Oui** pour installer, puis sur **Oui / Autoriser** si Windows demande l'accès au réseau.
4. Tape ton prénom. Mimi se loge maintenant près de l'horloge (une petite icône en forme de cœur) et démarre avec Windows.

## Connecter les deux PC (une seule fois)

Pour cette étape, les deux PC doivent être sur le même Wi-Fi.

1. Sur le premier PC, clique sur **Créer un code** : un code à 6 chiffres apparaît.
2. Sur le second PC, tape le code et clique sur **Rejoindre**. C'est fait 💞

## Utilisation

- **Ctrl + Alt + H** : envoie un cœur. Maintiens les touches enfoncées pour un gros cœur qui grandit.
- **Ctrl + Alt + M** : écris un message, ou envoie une image ou un GIF, affiché au milieu de l'écran.
- Appuie en même temps que ton partenaire pour une surprise.
- Clic droit sur l'icône en forme de cœur pour activer **Ne pas déranger** (de 10 minutes à 24 heures, ou jusqu'à ce que tu le désactives).
- Mimi se met à jour tout seul.
