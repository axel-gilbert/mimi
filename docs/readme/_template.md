# Mimi 💗

**Send little hearts to your other half's screen with one key.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi is a tiny free app for Windows. When you press a shortcut, small animated hearts float up in the corner of your partner's screen, with a cute sound. You can also send a big heart, a short message, a picture or a GIF. No account, no server: the two PCs talk directly to each other, and everything is encrypted.

## Install (on both PCs)

1. Download `Mimi-…-win-x64.exe` from the [latest release](https://github.com/axel-gilbert/mimi/releases/latest).
2. Double-click it. If Windows says *"Windows protected your PC"*, click **More info**, then **Run anyway**.
3. Click **Yes** to install, then **Yes / Allow** if Windows asks for network access.
4. Type your name. Mimi now lives next to the clock (a small heart icon) and starts with Windows.

## Connect the two PCs (only once)

Both PCs must be on the same Wi-Fi for this step.

1. On the first PC, click **Create a code**: a 6-digit code appears.
2. On the second PC, type the code and click **Join**. Done 💞

## Use it

- **Ctrl + Alt + H**: send a heart. Hold the keys down for a big heart that grows.
- **Ctrl + Alt + M**: write a message, or send a picture or a GIF, shown in the middle of the screen.
- Press at the same time as your partner for a surprise.
- Right-click the heart icon for **Do not disturb** (10 minutes to 24 hours, or until you turn it off).
- Mimi updates itself.
