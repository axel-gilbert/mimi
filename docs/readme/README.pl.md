# Mimi 💗

**Wysyłaj serduszka na ekran swojej drugiej połówki jednym klawiszem.**

<p align="center"><img src="../demo.gif" width="560" alt="Demo Mimi"></p>

Mimi to malutka, darmowa aplikacja dla Windows. Gdy naciśniesz skrót, w rogu ekranu twojej drugiej połówki wzlecą małe animowane serduszka, z uroczym dźwiękiem. Możesz też wysłać duże serce, krótką wiadomość, obrazek lub GIF. Bez konta, bez serwera: oba komputery rozmawiają ze sobą bezpośrednio, a wszystko jest szyfrowane.

## Instalacja (na obu komputerach)

1. Pobierz `Mimi-…-win-x64.exe` z [najnowszego wydania](https://github.com/axel-gilbert/mimi/releases/latest).
2. Kliknij go dwukrotnie. Jeśli Windows wyświetli komunikat *„System Windows ochronił ten komputer”*, kliknij **Więcej informacji**, a potem **Uruchom mimo to**.
3. Kliknij **Tak**, aby zainstalować, a potem **Tak / Zezwól**, jeśli Windows zapyta o dostęp do sieci.
4. Wpisz swoje imię. Mimi zamieszka obok zegara (mała ikonka serduszka) i będzie startować z Windows.

## Połącz oba komputery (tylko raz)

Do tego kroku oba komputery muszą być w tym samym Wi-Fi.

1. Na pierwszym komputerze kliknij **Utwórz kod**: pojawi się 6-cyfrowy kod.
2. Na drugim komputerze wpisz kod i kliknij **Dołącz**. Gotowe 💞

## Jak używać

- **Ctrl + Alt + H**: wyślij serduszko. Przytrzymaj klawisze, a urośnie duże serce.
- **Ctrl + Alt + M**: napisz wiadomość albo wyślij obrazek lub GIF, wyświetlane na środku ekranu.
- Naciśnij równo ze swoją drugą połówką, a czeka was niespodzianka.
- Kliknij prawym przyciskiem ikonkę serduszka, aby włączyć **Nie przeszkadzać** (od 10 minut do 24 godzin lub aż to wyłączysz).
- Mimi aktualizuje się samo.
