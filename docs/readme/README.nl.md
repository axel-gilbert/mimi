# Mimi 💗

**Stuur met één toets hartjes naar het scherm van je wederhelft.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi-demo"></p>

Mimi is een piepkleine, gratis app voor Windows. Als je op een sneltoets drukt, zweven er kleine geanimeerde hartjes omhoog in de hoek van het scherm van je partner, met een schattig geluidje. Je kunt ook een groot hartje, een kort bericht, een afbeelding of een GIF sturen. Geen account, geen server: de twee pc's praten rechtstreeks met elkaar en alles is versleuteld.

## Installeren (op beide pc's)

1. Download `Mimi-…-win-x64.exe` van de [nieuwste versie](https://github.com/axel-gilbert/mimi/releases/latest).
2. Dubbelklik erop. Als Windows *"Windows heeft uw pc beveiligd"* meldt, klik je op **Meer informatie** en daarna op **Toch uitvoeren**.
3. Klik op **Ja** om te installeren, en daarna op **Ja / Toestaan** als Windows om toegang tot het netwerk vraagt.
4. Typ je naam. Mimi woont nu naast de klok (een klein hartjespictogram) en start met Windows.

## De twee pc's koppelen (maar één keer)

Voor deze stap moeten beide pc's op hetzelfde wifi zitten.

1. Klik op de eerste pc op **Maak een code**: er verschijnt een code van 6 cijfers.
2. Typ op de tweede pc de code in en klik op **Deelnemen**. Klaar 💞

## Gebruiken

- **Ctrl + Alt + H**: stuur een hartje. Houd de toetsen ingedrukt voor een groot hartje dat groeit.
- **Ctrl + Alt + M**: schrijf een bericht, of stuur een afbeelding of GIF, midden op het scherm getoond.
- Druk tegelijk met je partner voor een verrassing.
- Klik met de rechtermuisknop op het hartjespictogram voor **Niet storen** (van 10 minuten tot 24 uur, of tot je het uitzet).
- Mimi werkt zichzelf bij.
