# Mimi 💗

**Šalji srca na ekran svoje bolje polovice jednom tipkom.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi je sićušna besplatna aplikacija za Windows. Kad pritisneš prečac, mala animirana srca lebde u kutu ekrana tvoje polovice, uz simpatičan zvuk. Možeš poslati i veliko srce, kratku poruku, sliku ili GIF. Bez računa, bez poslužitelja: dva računala razgovaraju izravno, a sve je šifrirano.

## Instalacija (na oba računala)

1. Preuzmi `Mimi-…-win-x64.exe` s [najnovijeg izdanja](https://github.com/axel-gilbert/mimi/releases/latest).
2. Dvaput klikni na njega. Ako Windows kaže *„Windows je zaštitio vaše računalo”*, klikni **Više informacija**, zatim **Ipak pokreni**.
3. Klikni **Da** za instalaciju, zatim **Da / Dopusti** ako Windows zatraži pristup mreži.
4. Upiši svoje ime. Mimi sada živi pored sata (mala ikona srca) i pokreće se sa sustavom Windows.

## Poveži dva računala (samo jednom)

Za ovaj korak oba računala moraju biti na istoj Wi-Fi mreži.

1. Na prvom računalu klikni **Stvori kod**: pojavit će se kod od 6 znamenki.
2. Na drugom računalu upiši kod i klikni **Pridruži se**. Gotovo 💞

## Korištenje

- **Ctrl + Alt + H**: pošalji srce. Drži tipke pritisnutima za veliko srce koje raste.
- **Ctrl + Alt + M**: napiši poruku ili pošalji sliku ili GIF, prikazane na sredini ekrana.
- Pritisni istovremeno sa svojom polovicom za iznenađenje.
- Desni klik na ikonu srca za **Ne uznemiravaj** (od 10 minuta do 24 sata ili dok ga ne isključiš).
- Mimi se ažurira sam.
