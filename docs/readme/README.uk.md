# Mimi 💗

**Надсилай серденька на екран своєї половинки одним натисканням.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi — крихітна безкоштовна програма для Windows. Коли ти натискаєш комбінацію клавіш, маленькі анімовані серденька злітають у кутку екрана твоєї половинки під милий звук. Можна також надіслати велике серце, коротке повідомлення, картинку чи GIF. Без акаунта, без сервера: два ПК спілкуються напряму, а все зашифровано.

## Встановлення (на обох ПК)

1. Завантаж `Mimi-…-win-x64.exe` з [останнього релізу](https://github.com/axel-gilbert/mimi/releases/latest).
2. Двічі клацни по ньому. Якщо Windows напише *«Windows захистила ваш ПК»*, клацни **Докладніше**, потім **Все одно виконати**.
3. Клацни **Так**, щоб встановити, потім **Так / Дозволити**, якщо Windows попросить доступ до мережі.
4. Введи своє ім'я. Тепер Mimi живе біля годинника (маленька іконка-серденько) і запускається разом із Windows.

## З'єднай два ПК (лише один раз)

Для цього кроку обидва ПК мають бути в одній мережі Wi-Fi.

1. На першому ПК клацни **Створити код**: з'явиться 6-значний код.
2. На другому ПК введи код і клацни **Приєднатися**. Готово 💞

## Як користуватися

- **Ctrl + Alt + H**: надіслати серденько. Утримуй клавіші, щоб отримати велике серце, що росте.
- **Ctrl + Alt + M**: написати повідомлення або надіслати картинку чи GIF, що з'являться посеред екрана.
- Натисни одночасно зі своєю половинкою — буде сюрприз.
- Клацни правою кнопкою по іконці серденька, щоб увімкнути **Не турбувати** (від 10 хвилин до 24 годин або доки не вимкнеш).
- Mimi оновлюється сам.
