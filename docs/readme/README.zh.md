# Mimi 💗

**一键就能把小爱心送到另一半的屏幕上。**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi 是一款小巧免费的 Windows 应用。按下快捷键，小小的动画爱心会伴着可爱的声音，飘现在另一半屏幕的角落。你还可以发送大爱心、短消息、图片或 GIF。无需账号，无需服务器：两台电脑直接通信，全程加密。

## 安装（两台电脑都要装）

1. 从[最新版本](https://github.com/axel-gilbert/mimi/releases/latest)下载 `Mimi-…-win-x64.exe`。
2. 双击运行。如果 Windows 提示 *“Windows 已保护你的电脑”*，点击**更多信息**，再点击**仍要运行**。
3. 点击**是**开始安装；如果 Windows 询问网络访问权限，点击**是 / 允许**。
4. 输入你的名字。Mimi 会住在时钟旁边（一个小爱心图标），并随 Windows 启动。

## 连接两台电脑（只需一次）

这一步需要两台电脑连接同一个 Wi-Fi。

1. 在第一台电脑上点击**生成配对码**：会出现一个 6 位数的配对码。
2. 在第二台电脑上输入配对码，然后点击**加入**。搞定 💞

## 使用方法

- **Ctrl + Alt + H**：发送爱心。按住不放，会发出越变越大的大爱心。
- **Ctrl + Alt + M**：写一条消息，或发送图片或 GIF，会显示在屏幕中央。
- 和另一半同时按下，有惊喜哦。
- 右键点击爱心图标，可以开启**勿扰模式**（10 分钟到 24 小时，或直到你手动关闭）。
- Mimi 会自动更新。
