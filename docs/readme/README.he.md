# Mimi 💗

**שולחים לבבות קטנים למסך של האהבה שלך בלחיצת מקש אחת.**

<p align="center"><img src="../demo.gif" width="560" alt="Mimi demo"></p>

Mimi היא אפליקציה קטנטנה וחינמית ל-Windows. כשלוחצים על קיצור, לבבות קטנים ומונפשים עולים בפינת המסך של בן או בת הזוג, עם צליל חמוד. אפשר לשלוח גם לב גדול, הודעה קצרה, תמונה או GIF. בלי חשבון ובלי שרת: שני המחשבים מדברים ישירות זה עם זה, והכול מוצפן.

## התקנה (בשני המחשבים)

1. מורידים את `Mimi-…-win-x64.exe` מ[הגרסה האחרונה](https://github.com/axel-gilbert/mimi/releases/latest).
2. לוחצים עליו פעמיים. אם Windows מציג *"Windows הגן על המחשב שלך"*, לוחצים על **מידע נוסף** ואז על **הפעל בכל זאת**.
3. לוחצים על **כן** כדי להתקין, ואז על **כן / אפשר** אם Windows מבקש גישה לרשת.
4. מקלידים את השם שלך. Mimi נמצא עכשיו ליד השעון (סמל לב קטן) ומתחיל עם Windows.

## מחברים את שני המחשבים (פעם אחת בלבד)

בשלב הזה שני המחשבים צריכים להיות באותה רשת Wi-Fi.

1. במחשב הראשון לוחצים על **יצירת קוד**: מופיע קוד בן 6 ספרות.
2. במחשב השני מקלידים את הקוד ולוחצים על **הצטרפות**. זהו 💞

## איך משתמשים

- **Ctrl + Alt + H**: שליחת לב. מחזיקים את המקשים לחוצים לקבלת לב גדול שגדל.
- **Ctrl + Alt + M**: כתיבת הודעה או שליחת תמונה או GIF, שמופיעים באמצע המסך.
- לוחצים באותו רגע עם האהבה שלך לקבלת הפתעה.
- לחיצה ימנית על סמל הלב פותחת **נא לא להפריע** (מ-10 דקות ועד 24 שעות, או עד שמכבים).
- Mimi מתעדכן לבד.
