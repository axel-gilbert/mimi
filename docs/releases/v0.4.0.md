**Mimi 0.4** ✨: a brand new message bar, and emoji that finally look right.

## A new message bar (Ctrl + Alt + M)

- Redesigned from scratch: **"To Léa"** header, rounded text field with a soft glow, round **send** button that lights up when there's something to send, native rounded corners and shadow on Windows 11.
- **Attachments preview**: the picture or GIF you're about to send shows above the text (animated for GIFs), with a little ✕ to remove it (or Backspace).
- **GIF picker**: search field, **category chips** (Trending, Love, Hug, Kiss, Miss you, Cute, Funny, Good night), a clean grid with rounded tiles, shimmering placeholders while loading, smooth scrolling and keyboard navigation (arrows + Enter). Pick a GIF, add a few words, press Enter.
- **Drag & drop** a picture onto the bar: a clear drop zone appears. Ctrl + V still works, and **Ctrl + G** opens the GIFs.
- Keyboard hints, a character counter near the limit, smooth open / close animations.

## Emoji & accents

- **Colour emoji everywhere Mimi draws text** (messages, captions, toasts, the bar, the settings): no more empty squares next to "In sync! 💞". Text is now rendered with DirectWrite, the modern Windows text engine, with every script supported.
- Long names, messages and captions are shortened without ever cutting an emoji or an accent in half.

## Also

- All new texts translated in the 31 languages.
