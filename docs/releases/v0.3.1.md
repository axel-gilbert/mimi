**Mimi 0.3.1** 🩹: fixes *"Network error: port 47777 is already in use"* after updating.

## Fixed

- **"Port 47777 is already in use" after the automatic update to 0.3.0.** The previous version started the new one in a way that passed it its open network socket, so the new version found its own port busy. Updates now start the new version cleanly, the socket can no longer be passed on, and a version started by an older updater relaunches itself cleanly once.
- **If another program really uses port 47777**, Mimi now picks a spare port (47778 to 47787) instead of stopping, and your partner's Mimi follows automatically. Pairing searches the whole range.
- If no port is free at all, Mimi tries again every 20 seconds instead of giving up.

## Update

- **On 0.3.0:** right-click the heart icon → **Check for updates** (or wait, it updates by itself within a few hours). If Mimi still shows the network error before that: right-click → **Quit**, then start Mimi again from the Start menu.
- **On 0.2 or new:** download **`Mimi-0.3.1-win-x64.exe`** below, double-click it, click **Yes**.
